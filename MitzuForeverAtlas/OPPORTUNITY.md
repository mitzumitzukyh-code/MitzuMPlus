# Opportunity status

**Current recommendation:** PIVOT / CONTINUE

The simple `dungeon maps only` niche is becoming more competitive. MitzuForeverAtlas should therefore evolve toward a Forever-specific **Dungeon Companion** rather than another generic Atlas replacement.

## Differentiation target

- Forever dungeon maps/floors only when native coverage is missing or materially incomplete.
- Boss preparation notes.
- Loot and profession Blueprint drops.
- Pre-pull CC/threat preparation that does not automate in-combat decisions.
- Dungeon quests and preparation checklists.
- Optional Camping/profession context relevant to a dungeon.

## Kill criteria

Pivot further or drop the map module if the Forever beta provides complete native dungeon maps or a dominant addon already solves the same problem better. Keep the preparation/data modules if they remain differentiated.

No unverified IDs, maps, bosses, loot, coordinates, or API assumptions should be added before beta validation.
