# CurseForge Project Page Draft

## Project name

MitzuMPlus

## One-line summary / Tagline

Mythic+ History, Player Profiles, Personal Bests, and Live Key Prediction.

## Main description - English

MitzuMPlus is a lightweight Mythic+ companion for World of Warcraft, built for players who want a cleaner way to review their dungeon history, track group performance, remember useful teammates, and follow live key outcome estimates.

The addon focuses on practical Mythic+ information without turning the interface into a combat-log dashboard. It keeps your run history organized, helps you identify personal bests, tracks players you have grouped with, and provides configurable live key prediction during a run.

### Key features

- Mythic+ run history with search, filters, sorting, pagination, favorites, notes, copy/export actions, and safe delete controls.
- Player profiles based on the people you have played with.
- Optional **Puntaje mítico** display through Raider.IO when the Raider.IO addon is installed.
- Personal best tracking for best key, timed improvements, performance milestones, and cleaner runs.
- Live key prediction HUD with configurable scale, opacity, lock state, ETA, confidence display, preview, and reset controls.
- End-of-run notifications and optional chat summaries.
- Group loot tracking with configurable minimum quality and item level.
- Built-in bug report window to make live testing easier.

### Optional addons

MitzuMPlus can use these addons when installed, but they are not required for the addon to load:

- Raider.IO
- LibSharedMedia-3.0

### Important note

MitzuMPlus does not automate gameplay and does not play the game for you. Experimental route arrows and route-alignment tools are intentionally kept in a separate development addon.

## Descripción en español

MitzuMPlus es un compañero ligero para Míticas+ en World of Warcraft. Está pensado para revisar tu historial de llaves, seguir tus mejores marcas, recordar jugadores con los que has jugado y ver una predicción limpia del resultado de la llave en vivo.

### Funciones principales

- Historial de Míticas+ con búsqueda, filtros, orden, paginación, favoritas, notas, copiar/exportar y eliminación segura.
- Perfiles de jugadores basados en compañeros con los que has hecho llaves.
- **Puntaje mítico** opcional usando Raider.IO si tienes instalado el addon Raider.IO.
- Seguimiento de marcas personales: mejor llave, mejoras de tiempo, rendimiento y runs limpias.
- HUD en vivo para predicción de llave con escala, opacidad, bloqueo, ETA, confianza, vista previa y reinicio de posición.
- Notificaciones al terminar una run y resumen opcional en chat.
- Registro de botín del grupo con calidad mínima e ilvl mínimo configurables.
- Ventana de Bug Report para facilitar pruebas en vivo.

MitzuMPlus no automatiza gameplay. Las flechas de ruta y herramientas experimentales de rutas se mantienen separadas en otro addon de desarrollo.
