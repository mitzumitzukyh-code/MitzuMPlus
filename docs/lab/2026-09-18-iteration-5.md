# Experimental M+ Lab — Iteration 5

Branch only: `experiment/mplus-lab-2026-09-18`. Stable/main/develop remain untouched.

## Fresh evidence checked

Public sources checked on 2026-09-18 reinforce both the product value and the performance constraint around Mythic+ Group Finder augmentation:

- NZT Group describes the concrete leader pain point as applicant volume arriving faster than it can be manually scanned, and exposes Lust/BRez as high-value composition facts.
- GroupFinder emphasizes preserving the native WoW experience, low resource usage, fast response and quiet behavior in combat; its current feature set also exposes applicant spec/rating and party utility context.
- OAK LFG Sorter changelogs repeatedly mention performance work, late Blizzard data, filtered-row refresh correctness and secret-number/taint handling. Its current project is All Rights Reserved and was used only as behavioral/API evidence.
- LFGBuddy continues to position reduced scrolling and composition filtering as its core value proposition.

These sources support Mitzu's current direction: augment Blizzard's native surface with a tiny factual hint rather than replace the browser, and treat event cost as a first-class constraint.

## Implemented: event-burst coalescing

The experimental `LFGCompositionHint` already avoided `OnUpdate` polling, but Blizzard can emit several roster/applicant/listing events in a single UI burst. Previously each event immediately rebuilt the same five-member party snapshot and rewrote the hint.

Iteration 5 adds `ScheduleRefresh()`:

- the first event schedules one zero-delay `C_Timer.After` callback for the next UI turn;
- additional events before that callback are coalesced;
- after the callback, a later independent burst can schedule normally;
- environments without `C_Timer.After` fail safely to an immediate refresh;
- no persistent ticker, polling loop, applicant scan, sort, filter or protected action is introduced.

This is intentionally a small performance-hardening iteration before any applicant-row surface is attempted.
