# Experimental Mythic+ Lab — Iteration 6

## Decision

Keep the Group Finder enhancement native and read-only, but reduce UI work further: the composition hint now caches its last semantic presentation and skips redundant `SetText`, `Show`, and `Hide` calls.

## Fresh evidence reviewed

- CurseForge `LFGBuddy` (updated 2026-09-09) explicitly targets the pain of repeated Group Finder scrolling and adds native-adjacent filtering/search memory.
- CurseForge `OAK LFG Sorter` (updated 2026-09-07) advertises performance improvements for scanning many listings/applicants and party-aware Lust/Battle Rez fit. Its license is All Rights Reserved, so no implementation code was copied.
- CurseForge `GroupFinder` (updated 2026-09-13) emphasizes low resource usage, fast response, quiet-in-combat behavior, native WoW experience, and applicant composition context.
- CurseForge `CompMatcher` (updated 2026-09-16) confirms current demand for live composition guidance while forming Mythic+ groups.
- CurseForge `NZT Group` documents a conservative public-LFG-API/read-only approach to applicant filtering and utility coverage.

The convergent product signal is not “replace Blizzard with a giant browser”; it is “surface the missing decision context with minimal interaction and minimal runtime cost.” Mitzu therefore stays additive rather than owning or filtering Blizzard rows.

## Implementation

`LFGCompositionHint:ApplyPresentation(value, visible)` tracks the last rendered localized text and visibility. Event bursts were already coalesced to one next-frame refresh; this iteration also makes unchanged refreshes effectively no-op at the UI-write layer.

No protected action, sorting, filtering, invite, decline, applicant mutation, or automatic keystone action was added.

## Localization

No new user-facing strings were introduced. The existing 13 experimental keys remain exactly paired between `enUS` (base/default) and `esES`.

## QA added

`tests/core/LFGCompositionHint.spec.lua` now checks that:

- first semantic state writes text and shows once;
- identical state performs no duplicate text/show writes;
- changed semantic text writes once;
- hide transitions happen once and repeated hides are cached;
- locale parity remains exact.

## Risk note

The enhancer still attaches only a child FontString to Blizzard's ApplicationViewer and does not hook protected actions. Live Retail verification remains required for layout/taint behavior because static Lua tests cannot reproduce Blizzard's secure UI environment.
